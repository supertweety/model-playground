Model contract & privacy

One embedded-weight ONNX file, up to 32 MiB. Float32 input image [1,1,64,64], float32 output logits [1,2], in O, X order. Use opset 18 and browser-supported operations. Scores use softmax.

Pixels use orientation-aware decoding, nearest pixel-center resizing, transparency on white, integer RGB grayscale, and normalization to [−1,+1]. The site checks the file contract and a trial inference; it cannot verify class order or training.

Models and photos stay in browser memory and are never uploaded or saved by this site. Refreshing clears selected files. Runtime files are served with this website. Startup requires a connection unless your browser has cached them. Browser HEIC support varies; JPEG/PNG is the reliable fallback.
