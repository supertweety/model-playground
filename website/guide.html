FROM PYTORCH TO YOUR PHONE

Your model, ready to try.

Export once, save the file, and select it in the playground. No upload or account is needed.

Try it first

Back in the playground, tap Try font demo. It loads a starter model and a printed O. Try the O/X sample buttons, then Run model.

The demo learned only synthetic printed letters in basic fonts. It may fail on handwriting and camera photos.

Download demo .onnx · Open playground

1. Export your PyTorch model

In a notebook opened at the repository root, after training your network:

from python.playground_export import export_for_playground

path = export_for_playground(
    model, "artifacts/my-ox-v1.onnx"
)

Your network must accept a grayscale 64×64 image and return two raw logits in O, X order. The helper checks the export and compares it with PyTorch. It leaves your original model unchanged.

2. Save the .onnx file on your phone

iPhone / iPad

AirDrop the exported file from your Mac and save it to Files, or use your own iCloud Drive folder. For a Safari download, open Files → Browse → Downloads (often under iCloud Drive, depending on settings). A folder called Model Playground makes your models easy to find.

Android

Download the model in Chrome, copy it over USB, or download a local copy from your own cloud storage. Look in Files / My Files → Downloads. You can keep it there or move it to a Model Playground folder.

Working in a notebook on your phone?

Download the exported file from the notebook first. In Colab:

from google.colab import files
files.download(str(path))

A file path inside Colab is not yet a file in your phone’s Downloads folder.

3. Choose it in the playground

  1. Return to Model Playground and tap Choose model.
  2. Browse to the saved .onnx file and wait for Ready.
  3. Draw, choose/take a photo, or try a printed sample. Inspect the grayscale preview and tap Run model.
“Choose model” keeps the file on your device.

Cloud transfers use your chosen provider. The playground itself does not upload or save student models. Refreshing clears the selection, but your saved file stays in Files/Downloads—just choose it again.

Can’t find or select the file?

Download the actual .onnx, not a sharing link or preview page. Unzip archives first. A .pt checkpoint must be exported, not renamed. If a cloud file is unavailable, save a local copy. Try regular Safari/Chrome if an embedded chat browser limits downloads.

Models must be one file with embedded weights, up to 32 MiB. For photos, JPEG/PNG is the reliable fallback when HEIC will not open.
